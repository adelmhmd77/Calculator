## Overview

This project is a lightweight calculator that runs entirely in the browser. It provides an on-screen keypad for entering numbers and basic arithmetic operators, with a display at the top. It is a static front-end project with no build step and no external dependencies referenced in the markup.

## Features

- On-screen button keypad with digits `0`–`9` and a decimal point (`.`)
- Basic operators: addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`)
- **AC** button to clear the whole input
- **DEL** button to erase a single entry
- **=** button to calculate the result
- Read-only display field, so input comes from the buttons only

## Getting Started

### Prerequisites

- A modern web browser

No package manager, build tools, or server are required.

### Installation

Clone the repository:

```bash
git clone https://github.com/adelmhmd77/Calculator.git
cd Calculator
```

### Usage

Open `index.html` in your browser, or try the hosted version at the [live demo](https://adelmhmd77.github.io/Calculator/).

Use the on-screen buttons to enter an expression, press **=** to calculate, **DEL** to erase an entry, and **AC** to clear everything.
